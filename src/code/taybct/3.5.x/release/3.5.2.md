# 3.5.2

基于 SpringBoot 3.5.6 开发的 Java 后端后台管理业务基础框架，常用的业务功能已经集成，开箱即用，相关使用说明，可以参考：

- [快速开始](../get-started/)
- [指南](../guide/)

## 主要更新

3.5.2 主要更新了工具升级和一些业务功能，以及修复一些配置错误

### 工具包

- 【新增】添加了 RustFS 文件管理默认实现，MinIO 现在已经转向商业模式，请自行更换为 commercial-minio

### 框架

- 底层升级
  - 【修复】修复 gradle 的一些配置错误
- 【更新】`spring-taybct-tools` 升级到 `3.5.2`
- 【新增】菜单路由消息通知数量统计（显示在菜单右上角的数量小角标），并且做了 websocket 默认实现，可以自定义实现
