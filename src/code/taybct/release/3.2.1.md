# 3.2.1

基于 SpringBoot 3.2.5 开发的 Java 后端后台管理业务基础框架，常用的业务功能已经集成，开箱即用，相关使用说明，可以参考：

- [快速开始](/code/taybct/get-started/)
- [指南](/code/taybct/guide/)

## 主要更新

- 工具包
  - 核心模块
    - 新增注解：[`@SyncToAnywhere`](/code/taybct/annotation/SyncToAnywhere)
  - 文件模块
    - OSS 去掉一些无用配置
- 框架
  - 安全
    - 新增[接口白名单访问功能](/code/taybct/guide/DeploySecurity.html#黑-白名单-3-2-1)
    - 黑/白名单过滤 ip 支持过滤 [cidr](https://cn.bing.com/search?q=cidr) 匹配 ip 规则
    - 删除原来的配置
      ```yaml
      taybct:
        secure:
          ignore:
            urls:
          black-list:
            urls:
      ```
      修改为：
      ```yaml
      taybct:
        secure:
          ignore:
            uris:
          black-list:
            uris:
      ```
  - 便捷性
    - 优化[后端业务代码模板](/code/taybct/guide/mybatisxTemplate)
    - 新增适配后端的[前端模板代码](/code/taybct/guide/mybatisxTemplate)
